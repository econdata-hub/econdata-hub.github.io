# Stata 计量笔记 · 配套数据

小红书「Stata 进阶」系列（07–17）配套数据与代码下载站（GitHub Pages）。

## 使用方法

1. 下载对应篇目的数据（`data/*.dta`）与代码（`code/*.do`），放入同一文件夹；
2. 在 Stata（建议 14 及以上）中运行 do 文件，即可复现帖子中的全部结果；
3. 也可以直接下载 `bundle.zip` 一次获取全部文件。

全部 11 篇代码已在 Stata 18（Windows）逐篇运行验证，无错误。
